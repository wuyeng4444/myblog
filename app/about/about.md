个人简介

你好，我是**无影**。

一个写设定的人。目前主要在做《帝国示录：我们是始嗣》——一部以「死亡帝国」为核心的世界观设定集。它从「始嗣」这个词开始，长到现在有上百个条目，还在长。

**🌑 在写的东西**

* **始嗣**：这套设定里最重要的一根钉子。不是种族名，更像一种「被写下过、于是必须存在」的东西。
* **帝国**：死亡帝国。权力怎么分配、法则怎么运转、谁在替谁死。
* **人物与神系**：极恶、欢颂、命定……他们撑起了这个世界的另一面。

设定集整理好的版本在这里：**[帝国示录 · 设定集](https://wuyeng4444.github.io/-/)**

**💻 顺带折腾的**

* 会用 HTML / CSS / JS 自己搭东西，这个站就是自己攒的。
* 会写点 Python 小脚本处理文本和图片——设定集那一百多个条目就是脚本从一份 txt 里切出来的。
* 不太喜欢把「能跑」当标准，好看也算标准的一部分。

**📝 这个站会放什么**

这里放我的作品、创作来路和日常记录。短的留在「说说」，长的写成文章；完整的世界观条目，继续整理在独立的设定集站里。
