# 网站内容管理

登录你自己的 GitHub 账号，打开对应文件，点击铅笔编辑。编辑完成后点击 **Commit changes…**，保存到 **main**。自动发布成功后刷新网站；一般需要几分钟。如果发布失败，之前的网站仍会保留，可查看 Actions 中的错误。

- `home-content.json`：首页介绍，只改引号中的文字。换行使用 `\n`。
- `moments.json`：说说列表，每个 `{ ... }` 是一条说说。修改时保留原 id；删除时移除整条；新增时复制示例并换成不同的 id。
- `works.json`：作品和网盘链接，提取码填在 code。

这些文件是公开内容，请勿填写登录密码、私人文件或密钥。图片可以通过仓库的 `public/gallery` 文件夹上传，在内容中填写 `/gallery/文件名.jpg`。

## 新说说示例

在 moments 数组中添加以下条目，和其他条目之间用逗号分隔。日期中的 `+08:00` 表示北京时间。

```json
{
  "id": "moment-20260913-001",
  "date": "2026-09-13T20:00:00+08:00",
  "content": "今天想记录的事情。\n第二段文字。",
  "location": "",
  "images": []
}
```

## 新作品示例

```json
{
  "id": "work-001",
  "title": "作品名称",
  "description": "作品简介",
  "url": "https://你的网盘链接",
  "code": "提取码，没有就留空"
}
```

JSON 使用英文双引号，最后一条后面不要加逗号。自动发布会检查格式；错误的内容不会覆盖已发布网站。
